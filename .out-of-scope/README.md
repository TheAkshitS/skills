# Out of Scope

Rejected feature requests and skill ideas that have been considered and
deliberately excluded. The `triage` skill (when added) checks this directory
before suggesting work on incoming requests.

## Format

Each file is a short markdown document named in kebab-case describing:

- **What** was proposed
- **Why** it was rejected or deferred
- **What to do instead** (if anything)
